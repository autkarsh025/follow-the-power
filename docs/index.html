Gigawatt Ledger

Tracking AI infrastructure from capex to the power grid. 26 companies across the AI supply chain, hourly power demand in 5 data-center hubs, all point-in-time, with an AI analyst whose every number is verified.

Utkarsh Agarwal Open data

What is this?

AI runs on GPUs, and GPUs run on electricity. When big tech spends hundreds of billions on AI, the money flows down a supply chain (chips, servers, power equipment, data-center buildings) and ends as electricity demand on the grid. This project follows that money and that power using only official public data, and asks honestly what each can and can't tell you.

The money

Quarterly revenue, capex and margins for 26 companies, from SEC filings. Every number keeps the date it became public, so history can be replayed without hindsight.

The power

Hourly electricity demand in 5 data-center hubs, with weather removed. Data centers run 24/7, so they raise the overnight load; a sudden jump can mean a new campus switched on.

The analyst

An AI analyst answers questions with tools: SQL, statistics and searching filing text. Every number it writes is checked against the data, and it's tested by replaying history.

Step-change detector

Weekly overnight load with weather, weekday and calendar-season effects removed. Markers show sudden, sustained jumps: the median of the next 8 weeks vs. the previous 8, above a robust noise threshold.

The AI analyst, and how it is kept honest

A language model answers finance questions by calling tools (point-in-time data, statistics, filing search, a calculator). Then code checks every number in its answer against what the tools returned; anything untraceable forces a rewrite. Quotes from filings must match the source word-for-word. Below: its test results and the receipts for every answer.

Tools, not memory

tools: financials for 26 companies, grid zones, weather adjustment, step detection, lead/lag, backtests, cited filing search, read-only SQL, calculator. Also served as an MCP server.

Verify every number

Each figure must match a tool result within rounding, or a figure quoted in the question. Unverifiable → revise (up to 2×). Quotes are checked against retrieved filing text.

Test like an auditor

Time travel (can't leak the future), planted false claims, refusing to invent forecasts, cited retrieval, multi-step math. Expected answers are computed from the data.

Glossary

Hyperscaler capex
Capital spending by Microsoft, Alphabet, Amazon and Meta: mostly data centers, servers and GPUs.
Overnight baseload
Median grid load between 1 and 5 AM. Homes and offices are quiet; data centers aren't.
Weather-adjusted (normalized)
Load with temperature effects removed using heating/cooling degree days, so growth isn't just a hot summer.
Degree days
How far the day's average temperature is below (heating) or above (cooling) 18 °C.
Point-in-time
Storing when each number was first published, so analyses only use what was known on a given date.
Restatement
A company later revising a number it already reported.
Year-over-year (YoY)
Growth vs. the same quarter a year earlier, which cancels seasons.
Trailing 12 months (TTM)
Sum of the last four quarters: smooths out lumpy quarters.
Noise band
About 2/√n. Correlations smaller than this are indistinguishable from chance with n points.
Nowcast
Estimating a number for a period that's over but not yet reported.
Load factor
Average load ÷ peak load. Data centers push it toward 1.
PUE
Power usage effectiveness: total facility power ÷ IT power (cooling and losses on top).
BM25
A classic search-ranking formula: passages with rare query words, used often, rank higher.
MCP
Model Context Protocol: a standard way to plug tools and data into AI assistants.
